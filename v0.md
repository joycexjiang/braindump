- If something in this file is ambiguous, use the default in §6 and say which one you used. Don't invent features from `plan.md` that aren't listed here.

## 1. What "done" looks like for v0

I open `localhost` in my browser every day and use it instead of Figma for collecting:
- I paste screenshots, links and videos onto canvases, cluster them and draw on them.
- Every day has its own page, and I can scroll back through past days.
- I have a running notepad with hover timestamps.
- Everything is saved as plain files in a folder on my laptop.

## 2. Stack and shape

| Piece | Choice | Why |
|---|---|---|
| Frontend | Vite + React + TypeScript | Fast, simple, what tldraw expects. |
| Canvas | **tldraw SDK** with its default UI hidden | Gets selection, pen, arrows, undo, zoom and paste for free (`plan.md` §5). |
| Local server | Small Node server (Hono or Express) on localhost, started with the frontend | Saves files to disk, serves media, and fetches link previews (browsers can't fetch other sites' metadata directly). |
| Storage | Plain files in a data folder (default `~/Diary`, set by `DATA_DIR`) | Readable, easy to back up, no database. |
| Run | `npm run dev` starts both | No build or install step needed. |

tldraw runs without a licence key on localhost in development, which covers personal use for v0. Confirm this in M0.

### Data folder

```
~/Diary/
  canvases/
    <id>.json        # { id, name, kind: "day" | "named", date, tags[], createdAt, updatedAt, snapshot }
  media/
    <sha256>.<ext>   # every pasted/dropped image or video, deduped by hash
  links/
    <sha256-of-url>.json   # cached link preview: { url, title, description, image, siteName, favicon, embed? }
  notes.jsonl        # one entry per line: { id, text, createdAt, updatedAt }
```

- `snapshot` is tldraw's document snapshot. Media in the snapshot points to `/media/<file>` URLs served by the local server, never base64.
- Save with a short debounce (about 1 second after changes stop) and on tab close. Write to a temp file and then rename, so a crash never leaves half a file.

### Repo layout

```
src/
  client/       # React app
    shapes/     # custom tldraw shapes: bookmark, video
    views/      # CanvasView, DayScrollView, NotesView
    sidebar/
  server/       # Node server: files, media, link previews
```

### M3: Day-scroll view
As described in `plan.md` §4.0:
- Clicking the **Canvases** heading opens a vertical scroll of all canvases ordered by date. Older pages are above, newer below, and it opens scrolled to today.
- As I scroll, past pages collapse into stacked header strips at the top (date on the left, project tags on the right). Click a strip to jump back.
- Inside a page, each cluster shows as a titled row with its items in a grid. Items not in any cluster show in an "Unsorted" row.
- Timeline scrubber on the right edge (day ticks, month labels, hover date pill, drag to scrub; taller ticks mean more items).
- Bottom pill shows the current date. Clicking it opens a date picker.
- Click a page to open it as the full canvas. `Esc` returns to the same scroll position.
- The stacked headers follow scroll position directly (no timed animations).

## 5. Ground rules

- **Personal project, kept apart from work:** personal GitHub, no Ramp systems, data or keys.
- The data folder is the source of truth. The app must never delete media files it didn't create, and every delete asks first.
- Basic tests only where logic is fiddly (the auto-layout function, the day-page dates, the link-preview parser). No test suite for UI.
